# Garmin Android Integration

## Project Documentation

This project integrates Garmin devices with Android via Bluetooth, USB, and WiFi. It allows for GPS data synchronization and navigation commands using the Garmin devices.

## Features
- Bluetooth communication for data transfer.
- USB communication for direct device connections.
- WiFi communication for online data synchronization.
- GPS data handling and navigation commands.

## Setup
1. Clone the repository.
2. Open the project in Android Studio.
3. Configure the build.gradle and AndroidManifest.xml as per your requirements.

## Usage
Use the provided classes and XML layouts to create your application. Refer to the documentation for detailed usage instructions.
