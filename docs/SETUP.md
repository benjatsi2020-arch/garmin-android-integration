# Setup and Installation Instructions for Garmin Android Integration

Welcome to the Garmin Android Integration project! Below are the setup and installation instructions to help you get started.

## Prerequisites
Before you begin, ensure you have the following installed:
- Android Studio
- JDK (Java Development Kit) 1.8 or higher
- Gradle 6.0 or higher

## Getting Started

1. **Clone the Repository**:
   Run the following command in your terminal:
   ```bash
   git clone https://github.com/benjatsi2020-arch/garmin-android-integration.git
   cd garmin-android-integration
   ```

2. **Open in Android Studio**:  
   Launch Android Studio and choose `Open an existing Android Studio project`. Navigate to the cloned `garmin-android-integration` directory.

3. **Sync the Project**:  
   Android Studio will prompt you to sync the project with Gradle files. Click on `Sync Now`.  

4. **Build the project**:  
   To build the project, select `Build > Make Project` from the toolbar.  

5. **Run the Application**:
   Choose an emulator or an Android device to run the application. Click on the `Run` button in the toolbar.
